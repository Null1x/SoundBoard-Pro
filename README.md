# SoundBoard-Pro
SoundBoard Pro — быстрый соундборд на Python (PyQt6) с кастомными QSS-темами и нулевой задержкой. Двойная маршрутизация аудио (одновременно в наушники и через VB-Cable в Discord/OBS), мгновенный поиск по звукам, автопроверка аудиоустройств при старте и сборка в единый автономный .exe со встроенными ресурсами.

# 🔊 SoundBoard Pro

**SoundBoard Pro** — это современный, высокопроизводительный десктопный соундборд, разработанный на **Python 3.10+** и **PyQt6**. Проект создан как легкая и отзывчивая альтернатива громоздким аналогам, страдающим от задержек воспроизведения и перегруженного интерфейса.

---

## 🛠️ Архитектура и технические особенности

- **🚀 Двойная маршрутизация звука (Dual Audio Routing):** 
  Приложение использует библиотеки `sounddevice` и `soundfile` для параллельной трансляции аудиопотока в два независимых устройства: в основные наушники пользователя и в виртуальный аудиокабель (VB-CABLE) для передачи звука в Discord, OBS или внутриигровой голосовой чат.

- **⚡ Low-Latency Воспроизведение:** 
  Оптимизированный движок воспроизведения запускает аудиофайлы в один клик без ощутимых задержек буферизации.

- **🎨 Кастомный UI/UX на PyQt6:** 
  Полностью переработанный интерфейс в глубокой тёмной теме с использованием кастомных стилей QSS, динамической анимацией нажатия кнопок, модальными окнами настроек и адаптивной сеткой звуков.

- **🔍 Мгновенная фильтрация:** 
  Встроенный поисковый движок на лету фильтрует массив звуковых файлов по ключевым словам, не нагружая основной UI-поток.

- **⚙️ Автопроверка окружения:** 
  При запуске программа автоматически анализирует список системных аудиоустройств и корректно инициализирует виртуальные кабели.

- **📦 Полная автономность и сборка:** 
  Реализована универсальная обработка путей к ресурсам (`resource_path`), что позволяет зашивать все графические активы (иконки `.ico`/`.png`) прямо внутрь единого `.exe` файла через PyInstaller, а также правильно отображать процесс в Диспетчере задач Windows через `SetCurrentProcessExplicitAppUserModelID`.
