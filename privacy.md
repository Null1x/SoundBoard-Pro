Политика конфиденциальности SoundBoard Pro

Дата: 18.10.2026 Контакт: limora342@gmail.com

1. Какие данные обрабатываются

SoundBoard Pro хранит на твоём компьютере:

список кнопок и их названия;

пути к звуковым файлам;

назначенные горячие клавиши;

настройки программы;

локальный лог работы Discord Rich Presence (если включено).

Эти данные сохраняются только на твоём устройстве.

2. Сетевые запросы

Программа обращается в интернет в двух случаях:

Проверка обновлений. При запуске программа отправляет запрос к GitHub (api.github.com) и узнаёт номер последней версии. В запросе передаются название и версия программы в заголовке User-Agent, а также, как и при любом запросе в интернет, IP-адрес твоего устройства. Имя, почта и другие личные данные не передаются.

Discord Rich Presence (необязательно). Если включена эта настройка, программа передаёт в Discord на твоём компьютере статус «Использует SoundBoard Pro». Связь идёт через локальное подключение к приложению Discord на твоём устройстве.

Программа не собирает персональные данные, не отправляет данные на сервер автора, не использует аналитику и рекламу.

3. Передача третьим лицам

Программа не передаёт данные третьим лицам. Запросы из раздела 2 идут к GitHub и к твоему локальному Discord, и только если они нужны для работы функций.

4. Хранение и удаление

Данные хранятся на твоём устройстве. Чтобы их удалить, удали папку с настройками программы или сам файл программы.

5. Дети

Программа не предназначена для сбора данных о детях. Если ты несовершеннолетний, используй программу с ведома родителей.
